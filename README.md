# Sunset City: Shivanshi Nigam's portfolio

An explorable open-world portfolio. Walk, drive, ride bikes and jet skis around a neon city at sunset. Every building with a glowing ring opens part of my work. All of it lives in the Downtown portfolio district.

**Play:** https://shivanshinigam.github.io/sunset-city-portfolio/

- `index.html`: the 3D city (Three.js)
- `2d.html`: the original top-down version
- `content.js`: all portfolio text, shared by both versions

Controls: WASD move · arrows / two-finger swipe turn the camera · scroll or pinch to zoom · V camera view · E enter · T talk · C "Ask me" · F get in a vehicle · P phone · K photo mode · M fast travel · R résumé view.
